# ۵۰ ایده برای ایجنتِ «مشاور تحصیلی + معلم + روانشناس»

> برای مرور chunk‌به‌chunk. هر ایده یک قابلیتِ مشخص است، نه یک آرزو.
> جلوی هر کدام: **س** = ساده (یک روزه)، **م** = متوسط، **د** = دشوار/عمیق.
> ریپوهایی که از تیک‌تاک درآمدند و راستی‌آزمایی شدند، در انتها جدول شده‌اند.

## ریپوهای تیک‌تاک — راستی‌آزمایی‌شده

ادعای تیک‌تاک را قبول نکردم؛ خودِ ریپوها را چک کردم:

| ریپو | ستاره | زبان | چه می‌کند | به‌دردِ کدام ایده |
|---|---|---|---|---|
| **`open-slide/open-slide`** | **۹٬۱۶۱** | TypeScript | «چارچوبِ اسلاید ساخته‌شده برای ایجنت» — با یک جمله، دکِ React با انیمیشن؛ روی هر عنصر کامنت بگذار، خودش اصلاح می‌کند | ۱۵ ⭐ |
| `dozentwelve/papermorph` | ۶۶۷ | HTML | PDF/کتاب → درسِ تعاملیِ گویندگی‌شده با آزمون، بدون مدلِ تصویرساز | ۱۸ |
| `vincentwei1021/mg-styles-15` | ۶۳۲ | Python | ۱۵ سبکِ موشن‌دیزاین، هر کدام فقط با کد (حتی موسیقی) + پرامپت و سورس | ۱۷ |
| `phreshos/system` | ۲۲۸ | TypeScript | سیستم‌عاملِ تحت‌وبِ self-hosted؛ اپ‌ها، فایل‌ها و ایجنت‌ها یک لاگین مشترک دارند | ۵۰ |
| `faviovazquez/showtime` | ۲۲۶ | Python | استودیوی ویدیوییِ محلی برای ایجنتِ کدنویس — بدون فرستادنِ یک فریم به ابر | ۱۶ |

دو ویدیوی دیگر (شبیه‌سازِ نقاشیِ روغن، فریم‌ورکِ تست به زبان ساده) ریپویی در توضیح نداشتند و پیداشان نکردم.

**نکته‌ی مهم:** `open-slide` با ۹۱۶۱ ستاره از بقیه یک سر و گردن بالاتر است و دقیقاً همان چیزی است که خواستی
(«پاورپوینت با انیمیشنِ حرفه‌ای»). پیشنهادم این است که chunk اول را از همین‌جا شروع کنیم:
نصب، تستِ واقعی، ساخت یک دکِ نمونه برای یکی از درس‌هایت.
