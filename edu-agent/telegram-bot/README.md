# ربات تلگرام: متن‌گیری فارسی از صوت و ویدیو (CPU)

ربات فایل صوتی یا ویدیویی را که کاربر برایش می‌فرستد، پردازش می‌کند و متن فارسی با زمان‌بندی برمی‌گرداند.

- **ASR:** Shenava Koochik v1.0 (CTC، Apache-2.0) با sherpa-onnx روی CPU. در تست FLEURS فارسی (۱۲ کلیپ) WER برابر ۹٫۵۲٪ و RTF حدود ۰٫۰۱ تا ۰٫۰۵ روی ۲ vCPU داشت.
- **اجرا:** GitHub Actions، هر ۶ ساعت یک بار، هر بار حدود ۵ ساعت و ۴۰ دقیقه. پیام‌های بین دو اجرا در صف تلگرام می‌مانند.
- **محدودیت:** Bot API فایل‌های بالاتر از ۲۰ مگابایت را دانلود نمی‌کند (`MAX_FILE_MB` پیش‌فرض ۱۹). برای فایل بزرگ‌تر باید Local Bot API راه‌اندازی شود.
- **هزینه:** مخزن **عمومی** باشد. در مخزن خصوصی، اجرای ۲۴ ساعته حدود ۴۳٬۲۰۰ دقیقه در ماه می‌شود و با سهمیه رایگان ۲٬۰۰۰ دقیقه‌ای، حدود ۲۴۷ دلار در ماه هزینه دارد (نرخ ۰٫۰۰۶ دلار برای هر دقیقه Linux 2-core).

## راه‌اندازی (یک بار)

1. در تلگرام با @BotFather یک ربات بسازید و توکن را بگیرید.
2. در GitHub: Settings → Secrets and variables → Actions → New repository secret:
   - `TELEGRAM_BOT_TOKEN` = توکن ربات
3. ربات را برای خودتان باز کنید و `/whoami` بفرستید. شناسه عددی را می‌گیرید.
4. secret دیگری بسازید: `TELEGRAM_ALLOWED_USER_IDS` = شناسه‌ها با کاما (مثلاً `123456789`).
5. Workflow را از تب Actions با `workflow_dispatch` اجرا کنید، یا منتظر زمان‌بندی بمانید.

> workflow فقط وقتی از روی زمان‌بندی اجرا می‌شود که روی شاخه پیش‌فرض باشد. قبل از merge می‌توانید از تب Actions اجرای دستی بگیرید، اما GitHub فقط اگر فایل روی شاخه پیش‌فرض باشد اجازه می‌دهد.

## تحلیل کانال‌های عمومی

این ربات فقط فایلی را پردازش می‌کند که کاربر مستقیم برای آن می‌فرستد. اسکرپ کانال یا جمع‌آوری داده از MTProto در این پوشه نیست. شرایط محتوای تلگرام استفاده از داده‌های پلتفرم برای AI را محدود کرده است. تصمیم برای هر مسیر دیگری با شماست و باید این محدودیت را در نظر بگیرد.
